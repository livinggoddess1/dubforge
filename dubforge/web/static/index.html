Dub a scene

Drop in an episode, pick the part you want, and press Start dubbing. Each step writes plain files you can edit, so you can fix a line and re-voice just that line.

  1. Separate voices from music and effects
  2. Transcribe the Japanese and find who's speaking
  3. Measure how each line is performed
  4. Write the English, then perform it in each character's voice
  5. Mix it back onto the original music and effects
